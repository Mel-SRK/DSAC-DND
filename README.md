# DND 地下城探险游戏

数据结构与算法课程设计。冒险小队进入地下城，逐层探索房间、与怪物战斗，并分配战利品。

## 构建与运行

需要支持 C17 的编译器、CMake 3.21 或以上版本，以及支持 UTF-8 的终端。Windows 下程序启动时会主动把控制台切到 UTF-8，直接双击 exe 也不会显示乱码。

~~~sh
cmake -S . -B build
cmake --build build
./build/dnd
~~~

运行时可用 `./build/dnd --seed 0` 固定先攻骰，便于复现一场探险。

## 首版玩法

第一层从入口到守卫室。守卫室连着储藏室和楼梯间。下楼后经前厅到达首领室，楼梯可以往返。

1. 开局选择战利品分配方式，按回车使用默认的队伍共有模式。
2. 输入编号选择相邻房间。首次进入有怪物的房间会自动开战。队员回合先选「普通攻击」或「法术」，再选攻击目标；怪物回合攻击当前生命值最低的存活队员，同血量时按队伍顺序选。
3. 行动顺序按速度从高到低排列，速度相同再比幸运。生命值跨房间保留，倒地角色跳过行动。
4. 可以绕路去储藏室开宝箱。赢下第二层的首领战即通关，全员倒地则失败，两种结果都会展示战利品结算。探索菜单输入 `0` 可退出。
5. 探索菜单里还能随时查看「人物属性」和「怪物图鉴」，图鉴只记录战斗中真正遇到过的怪物。

## 战斗规则

伤害分四种类型，人物与怪物的各项数值都限制在 0-99，启动时会校验。

| 类型 | 结算方式 |
| --- | --- |
| 斩击、打击 | 攻击伤害取力量；`扣血 = 攻击 - 防御`。防御高出攻击 51~70 时攻击者反受差值的一半，高出 71 以上时反受 70%，反噬直接扣血、不再减防御。 |
| 法术 | 伤害取魔力；魔抗 0 按全额扣除，魔抗 1~98 时 `扣血 = 法术伤害 / 魔抗`（向下取整），魔抗 99 免疫并反弹原伤害的 30%。 |
| 死亡 | 无视防御与魔抗，直接扣除对应生命。 |

法师的普通攻击恒为 1 点：每次独立掷 1% 死亡（99 点），其余斩击、打击各 49.5%。同一场战斗内第 100 次普攻若仍未掷中，则强制改按死亡结算；一旦出现死亡类型，计数归零，计数器每场战斗重置。

速度相同且幸运也相同时，跨队由队员按自己的幸运值掷 `n%` 决定先后，同队则按编号；怪物只提供幸运值参与比较，不掷骰。

战利品记录名称和价值，用于收集、分配和结算。

| 模式 | 分配规则 |
| --- | --- |
| 队伍共有（默认） | 物品全部进入小队仓库。 |
| 单场均衡 | 每场战斗或每个宝箱单独计算，将下一件物品分给本批收益最低的队员。 |
| 累计均衡 | 将下一件物品分给本趟探险累计收益最低的队员。 |

每批物品按价值降序处理。个人模式在全队三名队员之间分配，收益相同时按队伍顺序选人，结算时显示每人的总收益。

## 数据结构与算法

| 模块 | 实现 |
| --- | --- |
| `src/dungeon.c` | 地下城树记录层、房间和区域。遍历树统计战利品容量。房间的邻接表记录双向通道和楼梯，枚举当前房间出口的时间复杂度为 O(d)，其中 d 是房间的出口数。 |
| `src/combat.c` | 将存活角色加入数组实现的最大堆，按速度（同速比幸运）依次取出得到行动顺序，再处理同速同幸运的判定。n 个角色的排序时间复杂度为 O(n log n)。 |
| `src/loot.c` | 用稳定的插入排序按价值处理战利品。对 b 件物品、p 名队员，一批个人分配的最坏时间复杂度为 O(b² + bp)。 |

## 自动化测试

安装 Python 3 后配置、编译，再用 CTest 运行。测试使用 Python 标准库，向真实命令行程序发送预设输入并检查输出。

~~~sh
ctest --test-dir build --output-on-failure
~~~

也可以直接运行 `python3 tests/test_game.py ./build/dnd -v`。用例覆盖通关与战利品结算、房间往返与开宝箱、三种战利品分配模式、非法输入重试以及战斗中退出。
